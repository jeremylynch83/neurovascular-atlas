# Bounded right A4 shaft fit, v0.9.107

This fits only the middle of the right A4 shaft. The smooth Y-dependent shear translates the plateau 2.3 mm medially and 1 mm inferiorly, with compact support at source Y -53.5 to -37 mm and plateau Y -48.5 to -42 mm. All four native interfaces and their 324 shared coordinates remain fixed. Source vertices and triangles are retained; only positions and flank normals change. This improves a numerical cortical fit and does not resolve G05 or certify an anatomically correct complete ACA course.

Copy anatomy/source/aca-shaft-v0.9.107 to WORK before replaying, keeping the recorded evidence intact. Run from the app root with absolute WORK and CACHE paths.

- reconstruct.py WORK CACHE restores checked decoded source overrides and replays spec.json. The quintic bump gives a unit-determinant analytical shear with Y fixed. No source face may reverse. Source coordinate-weld partitions must be preserved, every original native boundary vertex must stay fixed, and changed coordinates must not create a new weld with any of the 766 arterial labels. Normal vectors on the sheared flanks use the inverse-transpose analytical Jacobian and are quantised once to SNORM16. Fixed-vertex and plateau normals remain exactly as stored. All three replayed buffers must match accepted byte for byte.
- validate_crossings.py WORK CACHE checks every changed face against all named scene surfaces, including self and adjacent faces. Closed target contacts are sent to the paired depth gate. Every other new positive crossing is rejected; no inherited non-neural crossing exists in this accepted correction. The only accepted closed contact target is the pre-existing right middle-anterior cingulate embedding.
- validate_depth.py WORK CACHE compares matching source/candidate corners, three edge midpoints and centroids of all changed triangles. It requires no new sampled entry, no increased depth beyond 0.001 mm, and agreement between signed distance and closed-volume parity. Open targets require conservative empty-ball separation. The fixed plateau bounds define the reported core independently of the results. Residual tissue embedding is explicitly retained.
- decode-normals.mjs SOURCE_GLB WORK/decoded extracts the original SNORM16 values listed in decoded/normal-inputs.json. Historical SOURCE_GLB is v0.9.106 complete-circulation.glb.
- export.mjs WORK SOURCE_GLB OUTPUT_GLB requires passing native-validation.json and writes lossless Float32 positions, exact candidate normal integers and source face indices. verify-export.mjs WORK [OUTPUT_GLB] needs WORK/old-complete-circulation.glb and checks all candidate buffers, unchanged physical-face corner normals, all source face indices, 598 other meshes in the asset and four other model assets.
- projections.py WORK CACHE requires exact source index lineage. Sanitised flips/removals, cap vertices and cap connectivity remain exact; all cap rims must stay fixed. It updates volume and checks closed/oriented topology. All 827 other proxy recipes stay exact.
- Preserve v0.9.106 flow as WORK/old-dsa-flow.json. Refresh only the ID in selected-course-ids.json, then run verify-flow.mjs WORK. All 596 other courses, selectability, directed connections, graph, vein sites, generator and unaffected edge distances must remain exact. The A4-dependent route distance is refreshed.

Baseline GLBs are not duplicated. NumPy, SciPy and VTK use the existing offline authoring environment. Rejected broad A2, connected A4-A5, short-taper and projected-branch trial results are preserved separately and are not installed. No full-atlas render was performed. The seven remaining zero-area triangles, PICA vermian crossing, other ACA/cortical embeddings, larger regional findings and ILT interface remain open.
