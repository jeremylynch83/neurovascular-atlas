# Arterial native wall repair, v0.9.100

The scan covers all 766 arterial meshes. This batch installs 15 passing wall-gap patches across five meshes with every original position, normal and face retained. See `docs/ARTERIAL_JUNCTION_BATCH8_v0.9.100.md` for scope and exclusions. The larger anatomical registration and receiving-lumen findings remain open.

Run from the application root using absolute paths:

- `python3 tools/arterial-junctions-v0.9.100/scan.py NEW_WORK CACHE` scans each mesh separately, cancels opposite native boundary edges by exact coordinates, and records small connected components with explicit loop ownership. It avoids assembling all 7.18 million arterial faces at once, retains single-label ports and excludes known bad-edge vertices. NEW_WORK must be fresh. It never edits a model or installs patches.
- Copy `anatomy/source/arterial-junctions-v0.9.100` as WORK to preserve the packaged evidence. `python3 tools/arterial-junctions-v0.9.100/repair.py WORK CACHE` replays the explicit accepted proposals against retained baselines, verifies mixed-label ownership and exact source-prefix retention, and requires byte-exact equality. It repeats changed-face/tissue/native-neighbourhood gates and the independent global edge-incidence check. Authoring dependencies are NumPy and VTK. It never installs a GLB.
- `global_edges.py` checks every appended coordinate edge against every named arterial source mesh. The baseline incidence is measured from actual triangles, including internal edges and labels outside the edited neighbourhood. Every affected edge must finish with exactly two opposite incidences. Touching an existing bad edge or creating a third incidence fails. This prevents local-only boundary cancellation from hiding a global topology regression.
- `node tools/arterial-junctions-v0.9.100/export.mjs WORK SOURCE_GLB OUTPUT_GLB` requires passing local and global edge reports. Original SNORM16 normal integers are preserved; appended coordinates/normals are copied from native neighbours without requantisation. Historical SOURCE_GLB is the v0.9.99 complete-circulation asset, not duplicated here.
- `node tools/arterial-junctions-v0.9.100/verify-export.mjs WORK [OUTPUT_GLB]` needs v0.9.99 `WORK/old-complete-circulation.glb`. It checks every selected source attribute/index prefix, the 594 other meshes in that asset and all four other GLBs.
- `python3 tools/arterial-junctions-v0.9.100/projections.py WORK APP` refreshes five DSA recipes from source-face lineage and paired-edge orientation constraints, requiring closed/oriented/positive-volume proxies.
- Preserve v0.9.99 flow as `WORK/old-dsa-flow.json`. Regenerate only the five IDs in `selected-course-ids.json` using `node tools/build-dsa-flow.mjs --only ID1,ID2,...`, then run `node tools/arterial-junctions-v0.9.100/verify-flow.mjs WORK`. The 592 other course entries, directed connections, graph, vein sites, generator and unaffected edge distances must match. Selected courses retain their original selectability. The complete generator marker is restored only after these checks.

The retained scan, source hashes, proposals, individual/global reports and checksummed buffers make the selection reviewable. Non-simple/degenerate candidates are deferred without another fan search. Ordinary automatic scanning still refuses malformed networks; this explicit batch is limited to checked native wall gaps and does not certify full anatomical lumens.
