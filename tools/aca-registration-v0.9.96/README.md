# Bounded right ACA registration and native falcine root, v0.9.96

This is a local part of the ACA/pericallosal batch. Bilateral A2-A5 registration and whole G06 receiving-lumen acceptance remain incomplete. The separate 12-segment arterial cohort still has one unresolved ILT interface. Runtime source, catalogue topology and all other meshes are retained.

The right A5 port was inside a closed posterior cingulate mesh. Shifting just that outlet previously folded its wall and moved other native ports inconsistently. The accepted construction uses a smooth X shear depending only on Y/Z, with a 2.1 mm amplitude, 2 mm plateau and 12 mm support. The adjacent precuneal branch uses a 5 mm geodesic taper constrained by the moved shared 148-coordinate root. A broader spatial branch field was excluded because it deepened the existing cortical embedding.

A 0.25 mm geodesic setback removes 168 malformed parent-lip triangles around the falcine outlet, keeping all other native boundaries fixed. This removes two of three existing local parent self-intersection pairs. A new collar connects the unchanged source branch above Z=121 mm to the resulting 32-coordinate opening. No Boolean or synthetic cap is included in the delivered junction. All 32 opposite native edges and normal integers match. One source self-intersection pair remains and is explicitly excluded from whole-lumen acceptance.

Source buffers, accepted arrays and reports are in `anatomy/source/aca-registration-v0.9.96`. Paths below are run from the application root; pass absolute work/cache paths. Work should be a copy of that source directory if you want to keep the original evidence untouched.

- `reconstruct.py WORK` stages `replayed/` and `sheared/` from `decoded/`. It requires NumPy, SciPy and VTK. It never installs an asset. Its physical triangle sets match the accepted arrays exactly.
- `validate_geometry.py WORK CACHE` compares `accepted/` with the baseline buffers and all scene meshes, including adjacent and coplanar intersections, moved exact native attachments, source orientation and network edges. It permits only demonstrably pre-existing self-intersection pairs. Two known closed cortical embeddings are sent to the separate paired depth gate rather than judged by contact counts alone.
- `validate_depth.py WORK CACHE` rejects new sampled tissue entry, additional depth beyond 0.001 mm numerical tolerance, or any inside samples on new triangles. It checks closed-volume parity against signed distance and uses conservative empty-ball surface bounds for open targets. The retained source embeddings are not declared resolved.
- `validate_collar.py WORK CACHE` applies the strict regional gate to the new collar with the staged parent and precuneal geometry. It requires zero changed-face crossings and no tissue entry.
- `preserve_normals.py WORK` writes final buffers to `candidate/`, retaining original corner normals and duplicate normal seams on every unchanged source triangle. Newly moved/new normals are computed across the connected labelled walls; fixed neighbouring label normals are copied exactly.
- `export.mjs WORK SOURCE_GLB OUTPUT_GLB` requires a passing `native-validation.json` and exports lossless Float32 positions, indices and SNORM16 normals. `verify-export.mjs WORK [OUTPUT_GLB]` loads that result through GLTFLoader and checks all candidate buffers, retained source corner normals, all 596 other arterial meshes and four other assets. For that historical comparison put the v0.9.95 arterial GLB at `WORK/old-complete-circulation.glb`; it is not duplicated in the release.
- `projections.py WORK APP` refreshes only the three DSA proxy recipes. It requires the source recipes to have no removed/reversed faces. Regenerate only the three selected flow IDs and run `verify-flow.mjs WORK` with the v0.9.95 `old-dsa-flow.json` to check all 594 reused entries, graph, vein sites and generator before restoring the complete generator marker.

The numerical gates show a bounded local correction, not independent anatomical certification. Retained source A5/precuneal cortical embedding, broader callosal registration, one local source self-intersection, dural/canal targets and full receiving lumens remain open. Rejected broad branch, narrowed-collar, Boolean and wider lip trials are documented so they need not be repeated.
