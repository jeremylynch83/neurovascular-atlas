# Galenic and torcular junction wall patches, v0.9.97

This batch closes 11 small mixed-label wall gaps with 61 triangles. It changes Galen, confluence and left inferior vermian display surfaces. All original positions, normal integers and triangles remain exact. The appended coordinates already exist in neighbouring labels. Vessel courses are not displaced.

The regional source network has 126 pre-existing non-manifold/misoriented edges. Ordinary automatic scanning correctly refuses to accept that whole network. The local review instead isolates directed boundary components away from every known bad-edge vertex. Only mixed-label loops smaller than 1 mm are considered; single-label ports, large boundaries, bad-edge components and unorderable boundaries are retained. Polygon ear clipping and a bounded existing-boundary-vertex fan search produce candidates. Every candidate still passes the strict whole-scene new-face gate. No source cap is installed as a substitute for a native junction.

The accepted Galen/precentral repair closes three local gaps. Other accepted patches lie at Galen/right posterior callosal, torcular/inferior vermian/occipital and inferior vermian/occipital seams. These local wall closures do not certify complete receiving lumens. The basal/Galen candidate inside the registered corpus callosum is excluded. Crossing fan alternatives, degenerate loops and wider malformed components are also excluded.

The source buffers, accepted proposals and reports are in `anatomy/source/galenic-junctions-v0.9.97`. Use a copy as a work directory if preserving the packaged evidence matters. Commands run from the application root and take absolute work/cache paths.

- `repair.py WORK CACHE` replays the explicit accepted proposals using content-addressed scene data and the retained baseline buffers. It writes to `replayed/`, requires exact source-prefix retention and byte-exact equality with `accepted/`, reruns the combined regional gate and returns non-zero on failure. It never installs a GLB. NumPy and VTK are authoring dependencies.
- `export.mjs WORK SOURCE_GLB OUTPUT_GLB` requires passing `native-validation.json`. It preserves original SNORM16 normal values, copies appended normals from their native source label, and exports lossless positions/indices with meshopt. For historical export comparison, put the v0.9.96 venous GLB at `WORK/old-venous.glb`; it is not duplicated in this release.
- `verify-export.mjs WORK [OUTPUT_GLB]` loads the export through GLTFLoader and verifies every original selected position, normal and face, all appended source coordinates/normals, the 228 other venous meshes and four other assets.
- `projections.py WORK APP` refreshes three DSA recipes using exact retained source-face lineage, then verifies closed and oriented proxy volumes. Preserve the v0.9.96 flow data at `WORK/old-dsa-flow.json`, run `build-dsa-flow.mjs --only __no_arterial_changes__` and `verify-flow.mjs WORK`. All 597 arterial courses, edges, graph and generator must remain exact. Only the three edited vein-site IDs could change; none change in this release.

The combined native boundary count drops from 8,162 to 8,079. All 126 existing bad edges retain their exact coordinates; none are introduced. All 1,254 potentially intersecting new-face triangle pairs pass. Closed tissue volumes have no inside samples on new faces; open targets use conservative surface-separation bounds. These are local numerical gates, not independent anatomical certification.

Galenic/callosal registration, residual parenchymal embedding, posterior arterial/sinus contacts, the detached torcular component, remote topology defects, independent dural/canal support and full receiving lumens remain open. No full-region render is needed for these bounded source-coordinate wall patches.
