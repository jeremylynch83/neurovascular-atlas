# v0.6.0: combined bilateral release

## Model and viewer

This release has one production scene. The separate ECA, anterior, TopBrain and legacy scenes, selectors and their unused assets are removed. Updates do not import old cached models. The user's existing persistent source data are left untouched.

The existing anterior/posterior circulation is joined to detailed ECA trees on both sides. Both carotid bifurcations use one skin, with normals calculated before splitting named parts. The left ECA starts from the approved right reconstruction and is independently fitted to the left bones. Side-specific courses are retained; runtime mirroring is not used where it would discard those adjustments. Potential connections are separate from the ordinary circulation and are hidden by default.

The original main jaw meshes did not include their separate alveolar processes, mandibular condyles or teeth. Restoring those 37 parts brings the craniofacial model to 60 named parts. Vertex comparisons of the shared maxillae and mandibular body confirmed coordinate agreement within 0.000007 mm. No arbitrary dental registration was applied.

Ghosted bone, including teeth, is excluded from ray-casting. Opaque bone can be selected. Hidden and section-clipped surfaces cannot intercept a click. A Face camera control frames the jaws and teeth. Craniofacial ghost opacity is higher than the cranial vault to keep the region legible.

## Refinements

The restored condyles and teeth exposed conflicts in existing vessel routes. Local corrections cover the STA, maxillary corridor, auricular branches, sublingual/submental/inferior labial courses, anterior inferior alveolar/incisive course and palatine branches. Changes propagate to child origins. Left posterior meningeal geometry was separated from PICA before joining, and the two greater palatine terminals remain separate.

The left ECA Angular and Middle temporal branches have distinct node names from the pre-existing intracranial branches with those names. Their display labels and vascular parents retain the correct territorial identity.

These changes are geometric fits to this atlas, not newly measured vascular anatomy. Calibre, depth, small canals and brain/vertebral relationships remain provisional and require anatomical review. Several skull-base and intraosseous routes intersect coarse bone meshes whose actual canals are not resolved. Such contacts must not be interpreted as validation of those canal walls.

## Compression and installation

Only three anatomy GLBs are shipped. Lossless Meshopt encoding is checked by decoding every buffer with the same decoder used by the viewer and comparing the bytes. Positions, normals, index order and detail are preserved. No decimation or coordinate quantisation is applied.

Nginx serves precompressed gzip files generated during the build. Model URLs carry SHA-256-derived revision identifiers and are cached; the manifest is revalidated. The source ZIP contains one copy of each asset, with gzip generated inside the Docker build rather than duplicated in the release ZIP.

Use the existing permanent installer. The normal installation consumes prebuilt models and does not install modelling dependencies.

## Verification and limitations

The final circulation has 385 named vessel parts, with 34 potential connection routes and 60 craniofacial parts. Independent validation confirms one closed oriented component and the intended genus 2. The critical triangle checks find no contact between the main ECA trunks and skull/jaw, or between vessels and the restored teeth/condyles. Occipital surface clearance is at least 0.55 mm on each side. See the accompanying JSON reports for measured topology, contact checks, compression and checksums. Real Three.js ray intersections test ghosted, opaque, hidden and clipped selection. GLTFLoader resolves every production asset binding. The TypeScript and production build checks pass. Review images are rendered directly from the final GLB triangles.

Live browser testing was unavailable: automatic approval review blocked execution of the bundled local browser harness, and the available cloud browser blocked access to localhost. Docker installation was not run in this environment. These are runtime verification limits, not a claim that the user-facing browser behaviour has been visually verified.

## Reproducibility

The separate authoring archive preserves the original input meshes, dense paths, source references, updated paths, rebuild scripts and validation scripts. It is not needed for installation. The production ZIP excludes historical anatomy and authoring masters. Start future territories from the current combined graph and preserve unique names across territories.
