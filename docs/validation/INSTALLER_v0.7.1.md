# Installer and Pages checks, v0.7.1

The app production build passed with `INR_BASE=/neurovascular-atlas/`. Generated HTML uses this base path for its JavaScript, stylesheet, favicon and anatomy manifest. A temporary static server under that subpath served the HTML, JavaScript, stylesheet, favicon, manifest and all three model URLs successfully (HTTP 200). All three GLB files are byte-identical to v0.7.0; this release changes installation and deployment only. The install ZIP excludes review screenshots, dependencies and build output.

Offline integration checks use real temporary Git repositories, with simulated Docker, GitHub CLI and HTTP calls. They cover empty-repository cloning, login and workflow-scope refresh, wrapped ZIP import, ignored model tracking, commit/push, Pages creation, repeat updates, existing releases, custom ignore rules, obsolete asset removal, switching legacy Pages to Actions while retaining the custom domain, local import followed by publishing, stale served versions, failed builds and container starts, ZIP traversal, Pages permission errors and retries, and divergent Git history. Run `python3 tools/test_installer.py` to repeat these checks; they do not perform anatomical review or contact GitHub.

Live Docker and authenticated GitHub deployment were not run in this workspace. On the user's computer, `inr-anatomy.sh` checks the actual served release before pushing. GitHub Actions performs the production build and deployment; the installer prints its URL and the Pages URL. A requested deployment is not a confirmed live deployment.
