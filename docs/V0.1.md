# v0.1 Foundation implementation

## Purpose

v0.1 converts the Dental Scope starter into an INR-specific foundation without pretending the final anatomical models have already been created.

## Implemented

1. **INR-specific UI and renderer.** Dental numbering, tooth dissection, periodontium, dental search and dental routing are no longer part of the active application.
2. **Anatomy-first catalogue.** Bone, arterial, venous and parenchymal context are first-class systems.
3. **Stable IDs.** Dotted identifiers are independent of display names and eventual GLB packaging.
4. **Provenance.** Geometry and reference provenance are explicit. Temporary starter geometry is labelled `legacy-placeholder`.
5. **Relationship graph.** Important spatial/anastomotic relationships are data, not implied by mesh intersections.
6. **Geometry-independent UI.** Planned structures can be searched and inspected before a model is attached.
7. **Headless validation.** `build-anatomy.sh` requires no GUI and validates the catalogue and GLB node references.
8. **Docker.** `docker.sh` builds and serves the production app.

## Deliberately not implemented yet

- CTA/CBCT/MRA/DICOM ingestion.
- Vessel segmentation or centreline extraction.
- Final skull model.
- Brain/parenchymal model.
- Final arterial or venous models.
- Teaching reconstructions of sub-resolution vessels.
- Expert anatomical approval state beyond the schema.

Those are v0.2+ work because source selection and master coordinate-space decisions must precede final modelling.
