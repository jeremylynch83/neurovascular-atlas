Neurovascular Atlas v0.9.21 anatomical review build, compact installation package.

Run ./docker.sh start, then open http://localhost:5173/.
For installer and publishing instructions, see README.md and the scripts included.

Includes the ventral pons advancement of up to 3 mm with the basilar artery and local pontine vessels, on the reviewed posterior-fossa build. PCA and deep venous fitting remain unfinished; rejected trials are excluded.

All 1,482 catalogue structures and all model triangles are retained. Models use delivery compression with maximum position rounding below 0.00022 mm. Historical review images and authoring trial models are omitted. See README.md and docs/validation/delivery-optimisation-v0.9.21.json.
